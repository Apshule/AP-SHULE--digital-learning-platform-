Task 8 — Step 1 of 2: Connection Settings Page + User Preferences

CONTEXT:
- Task 2 built offline PWA + triple mode (offline / mobile data / WiFi)
- Task 2 also created offline_settings IndexedDB table
- Now we build the user-facing Settings page so users can control 
  their experience
- This is a SMALL, POLISH task — no new heavy features

GOAL:
Every user (student, teacher, school admin) gets a "Settings" 
section in their Account page with:
- Connection preferences (data saver, auto-sync)
- Language preference (7 Ugandan languages)
- Storage management (see cached size, clear cache)
- Sync status display
- About + Help links
