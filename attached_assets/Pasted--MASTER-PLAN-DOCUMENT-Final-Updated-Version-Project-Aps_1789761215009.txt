📖 SECTION 1: PROJECT OVERVIEW

1.1 What Is This Project?

The Apshule Management System is a web-based school management platform that helps schools manage students, academics, finances, attendance, and communication. It serves three distinct user types, each with their own dashboard, permissions, and modules.

1.2 Project Goal

Build a system that:

· Allows a Secretary to manage students (Nursery to P7).
· Allows a Headteacher to manage Secondary students (S1-S6) with O-Level and A-Level report cards.
· Allows a Bursar to manage all school finances (fees, budgets, payroll, expenses, bank reconciliation).
· Works on both mobile phones and desktop computers.
· Generates professional PDF documents (report cards, ID cards, receipts).

1.3 Target Users

Role Email Example Primary Responsibility
Primary Secretary secretary@apshule.com Student records, ID Cards, Admission Letters
Secondary Headteacher headteacher@apshule.com Report Cards, Mark Entry, Grading
Bursar bursar@apshule.com Fees, Payments, Payroll, Budgets

🧩 SECTION 4: CORE MODULES (Detailed)

4.1 Authentication Module

· Login page with email + password.
· Account type dropdown (Primary / Secondary / Bursar).
· Role-based redirect after login.
· Password reset (email or SMS OTP).
· Logout with confirmation.

4.2 Dashboard Module

· Primary: Total Students, Active/Inactive, Students by Level chart, Class Size Distribution.
· Secondary: S1-S6 breakdown, O-Level vs A-Level counts, Streams Distribution.
· Bursar: Fees Collected, Outstanding Balance, Today's Collections, Fee Payment Status.

4.3 Students Module

· Primary: Nursery to P7 students, ID Cards, Admission Letters, Graduation Certificates.
· Secondary: S1 to S6 students, A-Level Combinations, Promotion.
· Shared Features: Search, Filter by Class/Gender/Status, Add/Edit/Delete, Import Excel, Export Excel/PDF.

4.4 Academic Module (Primary)

· Report Cards Dashboard (Mark Entry → Grade & Rank → Remarks → View Reports).
· Primary Grading Scale (A, B, C, D, E).
· Bulk Print Settings.

4.5 Academic Module (Secondary) — CRITICAL

· O-Level Report Cards (NCDC New Curriculum):
  · Columns: A1, U1, Avg/3, /100, Grade, Level.
  · Grading: A (2.4-3.0) to E (0.0-1.4).
· O-Level Report Cards (Old Curriculum):
  · Columns: U1-U4, AVE, Pts, Total/20, MT, EOT, Total 80%, Total 100%, Grade, Remark.
· A-Level Report Cards (UACE):
  · Columns: Code, Subject, Paper 1/2, A1, A2, A3, AVG, 20%, EOT, 80%, 100%, Grade, Comment, TR.
  · Project Work table.
  · Fees Balance / Fees Next Term.
  · Division calculation.
· Print Settings Modal (Template, Positions Toggle, Activities, Title, Initials).
· Online Parent Access (Authorize per student).
· Signature Management (Headteacher + Class Teacher).

4.6 Finance Module (Bursar)

· Fee Structures: Total fees, paid, balance per student.
· Record Payment: Amount, method (MTN/Airtel/Cash/Bank), reference, receipt generation.
· Optional Payments: Transport, Tours, Trips with rate options.
· Budgets: Year, Term, Allocated, Daily/Weekly/Monthly/Termly breakdown.
· Expenses: Category, Description, Payee, Amount, Status.
· Bank Reconciliation: Opening/Closing balance, transaction list, save draft, reconcile.
· Payroll: Prepare run, select staff, gross/deductions/net, approve.
· Staff Contracts: Issue, print PDF, expiry tracking.
· Learner Sponsorships: Type (Bursary/Scholarship), Amount, Source, Status.
· Reports: Collection, Expense, Budget vs Actual, Sponsorship.

4.7 Attendance Module

· Biometric dashboard (Total, Present, Late, Absent, Checked Out).
· 14-Day Trend chart.
· Check-In / Check-Out (Student, Staff, Daily Log).
· Attendance Reports with date range and CSV export.
· Attendance Records table.
· Biometric Device Setup (ZK series TCP/IP, Port 4370).

4.8 Communication Module (SMS)

· SMS Balance, This Month Usage, Total Sent.
· Bulk SMS: All Parents or Specific Classes.
· Manual numbers input.
· Character counter (160 chars), SMS count calculation.
· Balance check before sending.
· Recent SMS Activity log.

4.9 Settings Module

· My Profile (Name, Email, School, Role).
· Change Password.
· Configure Term Dates.
· 403 Access Denied Page.

⚠️ SECTION 10: CRITICAL NOTES FOR DEVELOPER

1. Report Cards Are Complex: The O-Level (NCDC), O-Level (Old), and A-Level report cards are completely different. Do not assume one template fits all.
2. Role-Based Access is Key: Never let a Primary Secretary see Bursar data, and vice versa.
3. Data Backup: Implement automatic daily database backups.
4. PDF Generation: Use a server-side library. Do not rely on window.print() for production.
5. SMS Costs: Ensure SMS balance is checked before sending. Deduct cost from school balance.
6. Security: Use HTTPS, hash passwords, sanitize all inputs.
7. Testing: Test every module on mobile (Chrome mobile view) before delivery.
