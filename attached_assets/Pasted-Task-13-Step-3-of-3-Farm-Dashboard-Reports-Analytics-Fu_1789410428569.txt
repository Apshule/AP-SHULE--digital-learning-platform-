PART B: FARM REPORTS MODAL
═══════════════════════════════════════════════════════════════

When Farm Admin taps [📊 Reports]:

Full-screen modal (id="farmReportsModal") with tabs:

TAB 1 — ANIMAL REPORTS

Sub-reports:
1. Animal Inventory Report
   - Current count per animal type
   - Morning vs evening counts
   - Missing animals (past 7 days)
   - Trend over time
   - [📥 Export PDF] [📥 Export Excel]

2. Animal Movement Report
   - All IN/OUT movements
   - Filter by date range, animal type, camera
   - Group by day
   - Average daily movement per animal type
   - Anomalies flagged (unusual times, directions)

3. Missing Animals Report
   - All missing animals logged
   - Status: recovered / still missing / lost
   - Days missing
   - Reported by

TAB 2 — PRODUCTION REPORTS

Sub-reports:
1. Egg Production Report
   - Daily/weekly/monthly egg counts
   - Broken egg rate (should stay under 2%)
   - Trays per hen per day (efficiency metric)
   - Peak production days
   - [📥 Export PDF]

2. Milk Production Report
   - Daily/weekly/monthly litres
   - Milk per cow per day (efficiency)
   - Morning vs evening yield
   - Grade breakdown (A/B/C)

3. Feed Consumption Report
   - Total feed consumed per animal type
   - Feed cost per day/week/month
   - Feed conversion ratio (kg feed per litre milk / kg meat)
   - Waste analysis

4. Produce Sales Report
   - All sales by produce type
   - Buyer analysis (top 10 buyers)
   - Revenue trends
   - Outstanding receivables

TAB 3 — WORKER REPORTS

Sub-reports:
1. Attendance Summary
   - Per worker: days present, absent, late
   - Attendance rate %
   - Monthly view
   - Export for payroll

2. Payroll Report
   - Base salary + days worked
   - Deductions for absences
   - Overtime (if tracked)
   - Net pay per worker
   - [📥 Export Excel for Payroll]

3. Worker Performance
   - Tasks completed per worker
   - Assigned animals
   - Productivity metrics (eggs collected, milk recorded)

TAB 4 — FINANCIAL REPORTS

Sub-reports:
1. Revenue Report
   - Daily/weekly/monthly revenue
   - By produce type
   - By buyer
   - Payment method breakdown

2. Expense Report
   - All expenses by category
   - Monthly trend
   - Top vendors

3. Profit & Loss Statement
   - Revenue − Expenses
   - Monthly + yearly
   - Net profit margin
   - Comparison to previous periods
   - [📥 Export PDF]

4. Cash Flow Report
   - Money in (sales)
   - Money out (expenses, payroll)
   - Net cash position
   - Outstanding receivables

TAB 5 — COMPLIANCE REPORTS

Sub-reports:
1. Animal Health Records
   - Vaccinations given
   - Vet visits
   - Illnesses treated
   - Mortality records
   - [📥 Export for MoA]

2. Milk Quality Log
   - Daily milk tests
   - Antibiotic residue records
   - Delivery to processors

3. Environmental Compliance
   - Waste management log
   - Water usage
   - Manure disposal

TAB 6 — CUSTOM REPORTS

Build custom:
- Select data source
- Select fields
- Apply filters
- Group by
- Sort by
- Preview
- [📥 Export PDF] [Excel] [CSV]
- [💾 Save as Template]
