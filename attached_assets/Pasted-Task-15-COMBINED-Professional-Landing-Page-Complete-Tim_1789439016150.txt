NEW FIRESTORE COLLECTIONS:

1. school_timetable_config

PART D: TIMETABLE AUTO-GENERATION ALGORITHM
================================================================

CORE FUNCTION generateTimetable with parameters institutionId, term, year, and options:

INPUT:
- All classes and their streams
- All subjects with periods per week
- All teachers with assignments
- Duty roster
- Config with periods, times, breaks
- Options:
  * Avoid teacher clashes (default yes)
  * Avoid room clashes (default yes)
  * Balance subject spread across week (default yes)
  * Keep practicals together (default yes)
  * Show expected outcomes column (default yes)

ALGORITHM:

Step 1: For each stream, compute total weekly periods needed.
Step 2: Build week template using constraint-based scheduling.
Step 3: Insert fixed entries for Assembly, Break, Lunch, and Duty teachers.
Step 4: Handle combined periods and lock them.
Step 5: Run conflict check for teacher clashes, room clashes, subject overload, and subject underload.
Step 6: Run optimization pass with swaps up to twenty iterations.
Step 7: Save as draft and notify admin.

MANUAL EDITING:
Admin can drag and drop subjects between periods, reassign teachers, add or remove a subject, mark any period as free or study, and add duty assignments. Conflict detection updates in real time with red highlights on clashes.
