PART D: TWIN CREATION PIPELINE
═══════════════════════════════════════════════════════════════

When Super Admin clicks "Create Digital Twin":

Show progress modal with steps:

STEP 1/4: Extracting audio from video... [progress bar]
STEP 2/4: Cloning teacher's voice...      [progress bar]
STEP 3/4: Creating AI avatar...           [progress bar]
STEP 4/4: Finalizing twin...              [progress bar]

IMPLEMENTATION:

Step 1 — Extract Audio:
- Load uploaded video into HTML5 <video> element
- Extract audio using AudioContext
- Convert to WAV or MP3
- Save to Firebase Storage:
  twins/{teacherId}/sample_audio.wav
- Track: duration, sample rate

Step 2 — Clone Voice (ElevenLabs API):
- POST to https://api.elevenlabs.io/v1/voices/add
- Headers: { 'xi-api-key': ELEVENLABS_KEY }
- Form data:
  * name: "APSHULE_{teacherName}"
  * files: [sample_audio.wav]
  * description: "Teacher twin for {subject}"
- Response: { voice_id: "...", ... }
- Save voice_id to teacher_twins.voiceModelId
- Test: Generate a short preview audio
  * POST to /v1/text-to-speech/{voice_id}
  * Text: "Hello, this is {teacherName} from APSHULE."
  * Save preview to Firebase Storage: twins/{teacherId}/voice_preview.mp3

Step 3 — Create Avatar (D-ID API):
- First: Extract a clear frame from the video
  * Use Canvas to capture frame at 0:05 seconds
  * Convert to base64 or upload to Firebase Storage

- POST to https://api.d-id.com/talks/streams (or /clips)
- Headers: 
  * Authorization: Basic {base64(DID_KEY:)}
  * Content-Type: application/json
- Body:
  {
    source_url: {frame image URL},
    script: {
      type: 'audio',
      audio_url: {voice preview URL}
    },
    config: {
      stitch: true,
      result_format: 'mp4'
    }
  }
- Response: { id: "...", status: "created" }
- Poll for completion (every 3 sec, max 2 min)
- When ready: get video URL
- Save avatar_id to teacher_twins.avatarId

Step 4 — Finalize:
- Update teacher_twins doc: status = "ready"
- Save createdBy, createdAt, lastUsedAt
- Cost estimate: $2.50 USD setup (~UGX 9,500)
- Increment twin_api_config.currentMonthSpend

Show success modal:
"✅ Digital Twin Ready!
 Teacher: {name}
 Voice cloned: ✅
 Avatar created: ✅
 [▶ Preview Twin] [📝 Generate First Lesson]"
