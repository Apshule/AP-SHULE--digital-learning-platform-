GOAL:
Automatically detect when a student's project looks too similar to another 
student's project in the same school. This is UNEB's anti-cheating requirement.
Detection runs in two ways:
1. Text similarity on title + description (>= 80% match)
2. Photo hash comparison on milestone photos (identical or near-identical)

When a duplicate is suspected:
- Set similarity_flag = true on the new project
- Set similarity_match_id = the doc ID of the matching project
- Set similarity_reason = 'text_match' or 'photo_hash_match'
- Notify the school admin (in-app notification)
- Show banner in student's project detail view (already built in Step 2)

PART A: TEXT SIMILARITY ALGORITHM
Add a helper function computeTextSimilarity(text1, text2):

1. Normalize both texts:
   - Lowercase
   - Trim whitespace
   - Replace multiple spaces with single space
   - Remove punctuation

2. Tokenize into words (split by space)

3. Build a word frequency map for each text

4. Compute cosine similarity:
   - Dot product of the two frequency vectors
   - Divided by (magnitude of vector 1 * magnitude of vector 2)
   - Return value between 0 and 1

Return the similarity score (0 to 1).

Do NOT use external NLP libraries. Pure JavaScript is enough.

PART B: TEXT SIMILARITY CHECK ON PROJECT CREATE
Modify saveNewProject() from Step 2:

After the project doc is written to Firestore:

1. Query all projects in the same school (schoolId == currentUser.schoolId)
   excluding the current project

2. For each existing project, compute similarity:
   - combinedText1 = newProject.title + " " + (newProject.description || "")
   - combinedText2 = existingProject.title + " " + (existingProject.description || "")
   - score = computeTextSimilarity(combinedText1, combinedText2)

3. Find the highest matching score

4. If score >= 0.80 (80% match):
   - Update new project doc:
     - similarity_flag = true
     - similarity_match_id = highestMatchId
     - similarity_reason = 'text_match'
     - similarity_score = score
   - Notify school admin via notifications collection:
     {
       type: 'duplicate_project',
       title: '⚠️ Possible duplicate project detected',
       body: '"{newTitle}" by {studentName} looks similar to "{existingTitle}" by {existingStudentName}. Review in Admin Panel.',
       timestamp: serverTimestamp(),
       author: 'System',
       targetUserId: schoolAdminUid (from appConfig)
     }
   - Show toast to student: "⚠️ Similar to another project — teacher will review"

5. If score < 0.80:
   - No action (project is unique)

PART C: PHOTO HASH COMPARISON
Add a helper function computeImageHash(imageDataUrl):

1. Load the image into a temporary <img> element
2. Draw it onto a small canvas (8x8 pixels) using drawImage
3. Get pixel data via canvas.getContext('2d').getImageData(0, 0, 8, 8)
4. Compute average brightness across all 64 pixels
5. Build a 64-bit hash string: for each pixel, if brightness >= avg 
   then '1', else '0'
6. Return the 64-character binary string

This is a perceptual hash (aHash) — two photos that look visually 
similar will produce hashes with small Hamming distance.

Add another helper hammingDistance(hash1, hash2):
1. Both hashes must be same length (64 chars)
2. Count positions where characters differ
3. Return the count (0 to 64)

Interpretation:
- distance == 0 → identical photos
- distance <= 5 → very similar (likely same photo)
- distance <= 10 → similar enough to flag for review
- distance > 10 → different photos

PART D: PHOTO HASH CHECK ON MILESTONE UPLOAD
Modify uploadMilestone() from Step 2:

After photo is compressed and before uploading to Firebase Storage:

1. Compute image hash from compressed photo:
   hash = computeImageHash(photoDataUrl)

2. Add this hash to project doc's photo_hashes array:
   - Use arrayUnion (Firebase) to append
   - Store as: { milestone: 1, hash: hash, uploadedAt: timestamp }

3. Query all other projects in the same school

4. For each project, compare new hash against every hash in their 
   photo_hashes array

5. If any match has distance <= 10:
   - Update current project doc:
     - similarity_flag = true
     - similarity_match_id = matchingProjectId
     - similarity_reason = 'photo_hash_match'
     - similarity_score = 1 - (distance / 64)
   - Notify school admin:
     {
       type: 'duplicate_photo',
       title: '⚠️ Possible duplicate photo detected',
       body: 'Photo uploaded by {studentName} for "{projectTitle}" matches a photo from another project. Review in Admin Panel.',
       targetUserId: schoolAdminUid,
       timestamp: serverTimestamp(),
       author: 'System'
     }
   - Show toast to student: "⚠️ Photo similar to another project"
