Task 6 — Step 3 of 4: Progress tracking, CPD certificate, and teacher earnings

CONTEXT:
- Step 1 created collections: ncdc_course_modules, ncdc_module_lessons, 
  teacher_retooling_progress, ncdc_cpd_certificates
- Step 2 built teacher-facing UI (video/PDF/quiz/practical per module)
- Now we add: aggregated progress tracking, CPD certificate generation, 
  and tie module completions into teacher earnings

GOAL:
- Teachers see their overall course progress with CPD point tracking
- When all 10 modules are completed, they auto-generate a verifiable

- Super Admin can view course progress across all teachers

Extend the course_enrollment doc created in Step 1:

Fields:
- teacherId
- enrolledAt
- modulesCompleted (number, 0-10)
- totalModules (number, 10)
- lastActivityAt
- cpdPointsEarned (number, calculated: modulesCompleted * 2)

- certificateId (string, empty until issued)
- certificateIssuedAt (timestamp)
- certificateUrl (string, empty until issued)

Add a helper recalcEnrollment(teacherId):
1. Query teacher_retooling_progress WHERE teacherId == uid
2. Count modules with moduleCompleted == true
3. Compute average quiz score across all quizzes taken
4. Update course_enrollment with recalculated values

Call recalcEnrollment after each module completion.

PART C: CPD CERTIFICATE GENERATION
═══════════════════════════════════════════════════════════════

When teacher completes Module 10 (final module):

1. Trigger automatic certificate generation:
   - Generate a unique certificateId: 
     Format: "APSH-CPD-{year}-{teacherId last 6 chars}-{random 4}"
     Example: "APSH-CPD-2026-A1B2C3-XK7P"
   - Compute SHA-256 hash of certificateId (for verification)
   - Generate PDF using jsPDF (already loaded)

2. PDF layout:
   - Landscape orientation, A4 size
   - Border: purple gradient
   - Header: "APSHULE DIGITAL LEARNING PLATFORM"
   - Title: "Certificate of Professional Development"
   - Subtitle: "NCDC Teacher Retooling Program"
   - Body: "This certifies that"
   - Teacher name (large, bold)
   - "has successfully completed the 10-module NCDC-aligned teacher retooling course, earning 20 CPD points."
   - List of 10 module names (small, two columns)
   - Completion date
   - Certificate ID (small, bottom left)
   - QR code (bottom right) — encodes verification URL
   - Signature line: "Wasswa Fred, Operations Supervisor"
   - AppShule logo top left

3. Upload to Firebase Storage:
   - Path: cpd_certificates/{teacherId}/certificate.pdf
   - Get download URL

4. Save to ncdc_cpd_certificates:
   {
     teacherId, teacherName, teacherEmail,
     issuedAt: serverTimestamp(),
     cpdPoints: 20,
     certificateUrl,
     certificateId,
     certificateHash, // SHA-256
     verified: true
   }

5. Update course_enrollment:
   {
     certificateIssued: true,
     certificateId,
     certificateIssuedAt: serverTimestamp(),
     certificateUrl
   }

6. Show celebration modal to teacher:
   "🏆 Congratulations!
    You've completed all 10 modules!
    Your CPD Certificate (20 points) is ready.
    [📥 Download Certificate] [Share]"

PART D: CERTIFICATE VERIFICATION PAGE
═══════════════════════════════════════════════════════════════

Add a public verification page (accessible without login):

When anyone scans the certificate QR, it opens:
https://appshule.com/verify/{certificateId}

Behavior:
1. Parse certificateId from URL
2. Look up in ncdc_cpd_certificates collection
3. If found AND verified == true:
   Show:
   ┌─────────────────────────────────────┐
   │ ✅ VALID CERTIFICATE                │
   │                                      │
   │ Teacher: {name}                     │
   │ Certificate: {certificateId}        │
   │ Issued: {date}                      │
   │ CPD Points: 20                      │
   │ Status: Verified                    │
   └─────────────────────────────────────┘
4. If not found or unverified:
   Show: "❌ Invalid or expired certificate"

Add this as a route inside the app (use hash routing since we're on GitHub Pages):
https://appshule.com/#verify/{certificateId}

The hash route works on GitHub Pages without server configuration.
