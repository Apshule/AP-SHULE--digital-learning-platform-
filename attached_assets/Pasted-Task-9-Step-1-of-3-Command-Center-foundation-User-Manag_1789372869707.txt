PART I: INSTITUTION BRANDING (CRITICAL FEATURE)
═══════════════════════════════════════════════════════════════

This is a PAID premium feature — institutions can add their own 
logo to the header alongside AppShule's logo.

NEW FIRESTORE COLLECTION: institution_branding
Fields:
- institutionId (string — reference to institutions)
- appshuleLogoPath (string — always the AppShule logo)
- institutionLogoPath (string — uploaded by Super Admin)
- institutionLogoAlt (string — alt text)
- institutionDisplayName (string — e.g. "Rosete Junior Day & Boarding")
- institutionTagline (string — e.g. "Excellence in Education Since 2005")
- primaryColor (string — hex code, optional)
- secondaryColor (string — hex code, optional)
- showAppshuleLogo (boolean, default TRUE)
- showInstitutionLogo (boolean, default TRUE)
- createdBy (string)
- createdAt (timestamp)
- updatedAt (timestamp)

   - AppShule logo below ("Powered by AppShule")

3. SPLASH SCREEN:
   - Both logos shown for 2 seconds on app load

4. REPORT CARDS (PDF):
   - Institution logo top-left
   - AppShule logo bottom-right ("Powered by AppShule")
   - Institution name in header

5. INVOICES / BILLS:
   - Institution logo prominent
   - AppShule credit at bottom

6. EMAIL / SMS TEMPLATES:
   - Institution name as sender
   - AppShule mentioned in footer

Role-based display:
- Student / Teacher / School Admin of institution X → See X's branding
- Super Admin → Sees only AppShule branding (not institution-specific)
- Cross-institution users → See AppShule branding only

Loading logic:
- On login, load user's institutionId
- Fetch institution_branding by institutionId
- If branding exists → apply
- If not → show only AppShule logo
