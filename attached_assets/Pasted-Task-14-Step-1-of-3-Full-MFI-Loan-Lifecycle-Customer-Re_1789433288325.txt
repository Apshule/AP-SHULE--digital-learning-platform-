PART F: REPAYMENT SCHEDULE GENERATION
═══════════════════════════════════════════════════════════════

After approval, auto-generate repayment schedule.

CALCULATION LOGIC:

For REDUCING BALANCE:
- Monthly rate = approvedInterestRate / 100
- Monthly payment = P × r × (1+r)^n / ((1+r)^n - 1)
  where P = principal, r = monthly rate, n = number of months
- For each month:
  * interest = remaining balance × r
  * principal = monthly payment - interest
  * balance = previous balance - principal
- Store principalDue, interestDue, balanceAfterDue

For FLAT RATE:
- Total interest = P × r × n
- Total repayment = P + total interest + fees
- Monthly payment = total repayment / n
- For each month:
  * principal = P / n
  * interest = total interest / n

FEES:
- Processing fee: deducted at disbursement (not in schedule)
- Insurance fee: spread across installments OR deducted upfront

GRACE PERIOD:
- If gracePeriod > 0:
  * First due date = disbursementDate + gracePeriod + firstCycle
  * Show "First payment due on {date}"

SCHEDULE CREATION:
- Create N mfi_loan_repayment_schedule docs (one per installment)
- Set dueDate based on repaymentFrequency
- Set status = "pending"

EXAMPLE (Small Business Loan):
- Principal: UGX 2,000,000
- Interest: 5%/month, Reducing
- Term: 12 months
- Monthly payment: UGX 225,558 (approximately)
- Schedule:
  ├─ Month 1: Principal 125,558, Interest 100,000, Balance 1,874,442
  ├─ Month 2: Principal 131,836, Interest 93,722, Balance 1,742,606
  ├─ Month 3: Principal 138,428, Interest 87,130, Balance 1,604,178
  ├─ ...
  └─ Month 12: Principal 214,855, Interest 10,703, Balance 0
