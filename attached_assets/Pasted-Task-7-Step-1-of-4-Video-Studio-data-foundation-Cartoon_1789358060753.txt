PART E: CARTOON VIDEO GENERATION PIPELINE
═══════════════════════════════════════════════════════════════

When Super Admin clicks "Generate Cartoon Video":

Show a progress modal (id="videoGenProgressModal") with steps:

STEP 1/5: Translating script...       [progress bar]
STEP 2/5: Generating voiceover...     [progress bar]
STEP 3/5: Selecting cartoon images... [progress bar]
STEP 4/5: Adding captions...          [progress bar]
STEP 5/5: Compiling video...          [progress bar]

IMPLEMENTATION:

Step 1 — Translate Script (if language != English):
- Call Gemini API with prompt:
  "Translate the following English script to {language}. 
   Keep simple primary/secondary level, Ugandan context, CBC values. 
   Return only the translated text, no explanations.
   Script: {scriptText}"
- Save to project doc as translatedScript
- If language == English: skip, translatedScript = scriptText

Step 2 — Generate Voiceover:
- Use Google TTS API (free tier via browser SpeechSynthesis)
  OR fallback: ElevenLabs if configured
- Split script into chunks of 200 chars max
- Generate audio for each chunk
- Combine into single audio file
- Save to Firebase Storage:
  projects/{projectId}/audio.mp3
- Save URL to project doc as audioPath

Step 3 — Select Cartoon Images:
- Based on character selection, fetch 6 images from cartoon_assets
  WHERE characterType == selected character
  Choose poses in sequence: standing → pointing → talking → writing → 
  smiling → talking
- If assets missing, generate simple SVG placeholders
- Save image URLs to project doc

Step 4 — Add Captions:
- Split translatedScript into 6 segments (one per image)
- Generate SRT file content:
  1
  00:00:00,000 --> 00:00:30,000
  {segment 1 text}

  2
  00:00:30,000 --> 00:01:00,000
  {segment 2 text}
  ... etc
- Save as string in project doc as captionsSrt

Step 5 — Compile Video:
- For offline version (slideshow):
  * Store 6 images + audio + captions as separate fields
  * Do NOT render MP4 (browser can play as slideshow)
  * Total size: ~2-3MB
  * Save as videoPathOffline (just metadata URL)
- For HD version:
  * If Super Admin wants MP4, they can upload separately
  * For now, set videoPathHd = "" and show "Use offline version"

After all 5 steps complete:
- Update project doc: status = "ready"
- Show success modal:
  "✅ Cartoon Video Ready!
   Topic: {topic}
   Language: {language}
   Duration: {duration}
   
   [▶ Preview] [📥 Download] [📝 Publish to Schools]"
