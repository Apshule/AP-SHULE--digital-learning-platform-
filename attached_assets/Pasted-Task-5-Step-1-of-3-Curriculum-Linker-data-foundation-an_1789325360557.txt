PART A: VERIFY CURRICULUM_LINKS COLLECTION STRUCTURE
═══════════════════════════════════════════════════════════════

Ensure each curriculum_links document has these fields:

Required:
- subject (string) — e.g. "Mathematics", "Biology"
- classLevel (string) — e.g. "P1" through "P7", "S1" through "S6"
- topic (string) — e.g. "Fractions", "Photosynthesis"
- syllabusRef (string) — e.g. "Mathematics Syllabus P5, p.34"
- learnerBookPage (string) — e.g. "Learner Book P5, p.56-60"
- teacherGuidePage (string) — e.g. "Teacher Guide P5, p.42-45"
- summaryText (string) — 200-word max summary of the topic
- activitySuggestion (string) — a suggested CBC activity

Optional:
- syllabusUrl (string) — link to full syllabus PDF if available
- learnerBookUrl (string) — link to learner book PDF
- teacherGuideUrl (string) — link to teacher guide PDF
- competencies (array of strings) — CBC competencies covered
- genericSkills (array of strings) — e.g. "critical thinking", "communication"
- values (array of strings) — e.g. "respect", "responsibility"
- createdBy (string) — uid of admin who added
- createdAt (timestamp)
- updatedAt (timestamp)
- searchKeywords (array) — lowercase keywords for fast search
  (auto-generated from topic + subject)

Do NOT delete existing documents. ADD any missing fields to 
existing records with sensible defaults.

═══════════════════════════════════════════════════════════════
PART B: CREATE SEARCH KEYWORDS AUTOMATICALLY
═══════════════════════════════════════════════════════════════

Add a helper function generateSearchKeywords(topic, subject, classLevel):

1. Combine: topic + " " + subject + " " + classLevel
2. Lowercase everything
3. Split into individual words
4. Remove common stop words (the, a, an, of, and, or, in, on, at, to, for)
5. Remove duplicates
6. Return as array of strings

Example:
Input: topic="Photosynthesis", subject="Biology", classLevel="S2"
Output: ["photosynthesis", "biology", "s2", "photo", "synthesis"]

Use this when creating or importing curriculum_links documents.
Store the result in searchKeywords field.
