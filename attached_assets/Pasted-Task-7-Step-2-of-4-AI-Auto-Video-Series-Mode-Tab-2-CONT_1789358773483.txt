PART B: AI VIDEO GENERATION PIPELINE (Single Video)
═══════════════════════════════════════════════════════════════

When Super Admin clicks "Generate AI Video" (Single mode):

Show progress modal with steps:

STEP 1/6: Generating lesson script...    [progress bar]
STEP 2/6: Translating (if needed)...     [progress bar]
STEP 3/6: Generating voiceover...        [progress bar]
STEP 4/6: Selecting visuals...           [progress bar]
STEP 5/6: Adding captions...             [progress bar]
STEP 6/6: Compiling video...             [progress bar]

IMPLEMENTATION:

Step 1 — Generate Lesson Script:
Call Gemini API with this prompt:
"You are Ugandan CBC expert. Generate a {duration}-minute video 
lesson script for the topic: {topic}.
Subject: {subject}. Class: {classLevel}. Difficulty: {difficulty}.

Include in the script:
- Introduction (30 sec) — hook with real-life Ugandan scenario
- Main content (multiple sections) with:
  * Clear explanations
  * Ugandan examples (mangoes, matooke, market, boda boda, etc.)
  * CBC values demonstrated
  * Generic skills practiced
- Summary (30 sec)
- 3 quiz questions at the end

Format with timestamps in [MM:SS] format at the start of each 
section. Total duration must be approximately {duration} minutes.
Script should be read aloud by a teacher voiceover — keep sentences 
short (under 20 words)."

Save to project doc as scriptText.
Show loading spinner (5-15 seconds typical).

Step 2 — Translate (if language != English):
Same as Task 7 Step 1 Cartoon pipeline — reuse translateScript().

Step 3 — Generate Voiceover:
- Split translatedScript into chunks of 300 chars
- Use browser SpeechSynthesis API (works offline!)
- Select voice matching language:
  * English: en-US or en-GB voice
  * Swahili: sw-KE if available
  * Other Ugandan languages: fallback to en-US voice reading 
    phonetic text
- Playback optimization:
  * Reduce speech rate to 0.9 (slightly slower for students)
  * Pitch 1.0
- Save audio as WebM blob to Firebase Storage:
  projects/{projectId}/voiceover.webm

Step 4 — Select Visuals:
Based on visualStyle:
A. Cartoon:
   - Query cartoon_assets
   - Select images matching subject keywords
   - Default: 1 image per 30 seconds of video
   - Rotate through poses to keep interest

B. Stock images (Pixabay):
   - Call Pixabay API (free, no key needed for basic)
   - URL: https://pixabay.com/api/?key=demo&q={topic}&image_type=photo&per_page=20
   - Download top 20 images
   - Rotate through them
   - Cache locally

C. Slideshow (simplest):
   - Extract keywords from script
   - Generate simple colored text slides using Canvas API
   - Each slide: title + key point + simple icon (emoji)

Save image URLs/array to project doc.

Step 5 — Add Captions:
Split translatedScript into segments:
- Calculate duration per segment = totalDuration / segmentCount
- Generate SRT:
  1
  00:00:00,000 --> 00:00:30,000
  {text for segment 1}

  2
  00:00:30,000 --> 00:01:00,000
  {text for segment 2}
  ...

Save as captionsSrt field.

Step 6 — Compile:
For Single Video:
- Store: 6-12 images + audio + captions
- Total size: ~5-10MB (audio-heavy)
- Save to videoPathOffline
- HD version: skip for now (see Step 4 for optional upload)

Update project doc:
{
  status: "ready",
  durationMinutes: {duration},
  ...
}

IMPLEMENTATION:

Step 1 — Generate Master Script:
Call Gemini API with prompt:
"You are Ugandan CBC expert. Generate a complete {totalTime}-minute 
lesson on {topic} for {subject} {classLevel}.

Split the lesson into {segmentCount} segments of approximately 
{segmentLength} minutes each. Each segment should be a 
self-contained mini-lesson.

For each segment provide:

- 3 learning objectives
- Content (2-3 paragraphs)
- One Ugandan real-life example
- One activity for learners
- One assessment question

Segments should build on each other logically:
Segment 1: Introduction & overview
Segments 2-{N-1}: Main concepts
Segment {N}: Summary & quiz

Return as a JSON array:
[
  { "number": 1, "title": "...", "script": "...", "objectives": [...], ... },
  ...
]"

Step 6 — Create 6 separate video_studio_projects:
- Each with seriesParentId = masterProjectId

- All share the same topic, subject, classLevel

Update masterProject:

Intelligent image selection from cartoon_assets:

Add function selectBestImages(topic, subject, count):

1. Extract keywords from topic + subject
   - "Photosynthesis Biology S2" → ["photosynthesis", "biology", "s2"]

2. Query cartoon_assets WHERE tags array-contains-any keywords
   - If results found: use those
   
3. If no matches: fall back to random selection from all assets

4. Ensure variety:
   - Pick different poses
   - Pick different characters
   - Order: standing → pointing → talking → writing → smiling → talking

   - Rotate through assets multiple times
   - Add slight variation (different captions)
