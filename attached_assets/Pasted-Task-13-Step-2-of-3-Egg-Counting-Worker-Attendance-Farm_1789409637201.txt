PART C: WORKER ATTENDANCE VIA FACIAL RECOGNITION
═══════════════════════════════════════════════════════════════

Reuse facial recognition infrastructure from Task 4.

WORKER ENROLLMENT:
When Farm Admin adds a worker (Step 1) and uploads a face photo:
1. Compute face embedding
2. Save to farm_workers.faceEmbedding
3. Worker is now recognized at any camera set to 
   "worker_attendance" mode

ATTENDANCE FLOW:

Morning check-in:
1. Worker approaches camera at gate or main entrance
2. Camera captures face
3. Match against farm_workers.faceEmbedding
4. If matched with confidence > 85%:
   - Create farm_worker_attendance doc
   - checkInTime = now
   - status = present (or late if after 8:30 AM)
   - Send in-app notification to worker
5. If matched with 60-85% confidence:
   - Flag for manual review
   - Notify Farm Manager
6. If < 60% confidence:
   - Show "Not recognized" to worker
   - Provide fallback: manual check-in via PIN or manager approval

Evening check-out:
- Same process at end of day
- Update attendance doc with checkOutTime
- Compute hoursWorked
