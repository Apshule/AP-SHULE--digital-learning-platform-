PART C: SEARCH LOGIC
═══════════════════════════════════════════════════════════════

Add function searchCurriculumLinks(query, filters):

1. Normalize query: lowercase, trim, split into words

2. If ONLINE:
   - Query Firestore curriculum_links
   - Use searchKeywords array-contains-any for each word
   - Apply filters (subject, classLevel) if set
   - Limit 20 results

3. If OFFLINE:
   - Query offline_curriculum_links in IndexedDB
   - Filter locally by searchKeywords + filters
   - Limit 20 results

4. Ranking (client-side after fetching):
   - Exact topic match: 100 points
   - Topic starts with query: 80 points
   - Topic contains query: 60 points
   - Keyword match: 40 points
   - Sort by score desc, then alphabetically

5. Return array of matching records

PART F: GENERATE CBC ACTIVITY BUTTON
═══════════════════════════════════════════════════════════════

Below the tabs, add a big button:
"📄 Generate CBC Activity (AI)"

Behavior:
1. If ONLINE:
   - Call Gemini API with this prompt:
     "You are Ugandan CBC expert. Topic: {topic}. 
      Subject: {subject}. Class: {classLevel}.
      Syllabus reference: {syllabusRef}.
      Generate a CBC activity with:
      - A real-life Ugandan scenario
      - 2-3 CBC values to demonstrate
      - Generic skills practiced
      - Assessment criteria (Exceeds/Meets/Approaching/Needs Support)
      - Time: 40 minutes
      Use only NCDC competency-based materials for Lower Secondary 
      and New A-Level 2025. Cite NCDC page references when applicable.
      Format: markdown with clear headings."
   - Show loading indicator
   - Display result in a modal (id="generatedActivityModal")
   - Modal has: [📥 Download PDF] [📋 Copy] [🔄 Regenerate] buttons

2. If OFFLINE:
   - Show cached activitySuggestion from curriculum_links
   - Show banner: "Offline — showing pre-saved activity. 
     Connect for AI generation."

3. If Gemini API key not configured:
   - Show fallback: use activitySuggestion
   - Log warning
