  (40 docs), teacher_retooling_progress, ncdc_cpd_certificates collections
- Super Admin can seed the course content
- Now we build the teacher-facing UI to actually take the course

GOAL:
Teacher taps "NCDC 10 Modules Course" in Teacher Dashboard → sees:
- Course overview page with 10 modules
- Progress bar (X of 10 completed)
- Each module card shows status (locked / available / in-progress / done)
- Tapping module opens lesson viewer with 4 sequential lessons:
  1. Video (YouTube embedded)
  2. PDF summary (opens in existing pdf modal)
  3. Quiz (5 questions, passing score 3)
  4. Practical upload (photo/file)
- After all 4 lessons complete → module marked done
- Next module unlocks

═══════════════════════════════════════════════════════════════
PART F: QUIZ ENGINE
═══════════════════════════════════════════════════════════════

When teacher taps [📝 Take Quiz]:
- Open quiz modal (id="ncdcQuizModal")
- Load 5 questions from lesson.contentData.questions

Quiz UI:
- Question 1 of 5
- Question text
- 4 radio button options (A, B, C, D)
- [Next] button (disabled until an option is selected)
- Progress bar at top showing question number

After all 5 questions:
- Show results screen:
  * "You scored 4/5"
  * List of questions with correct/incorrect indicators
  * Show correct answers for wrong ones
  * If score >= 3 (passing):
    - [✅ Pass — Return to module] button
    - Save to teacher_retooling_progress:
      { lessonOrder: 3, completedAt, score: 4, passed: true }
  * If score < 3 (fail):
    - [🔄 Retake Quiz] button
    - [Return to module] button
    - Do NOT mark as complete
    - Max 3 attempts per session

Offline behavior:
- Quiz works fully offline (questions cached)
- Result saved to IndexedDB offline_teacher_progress
- Syncs to Firestore when online
