PART B: CONNECTION DETECTION (TRIPLE MODE)

Add a global connection manager that detects:

A. OFFLINE MODE (0 MB data):
   - navigator.onLine === false
   - Show green badge: "Offline Mode - Working, will sync at school"
   - All features work from cache
   - Videos: Play cached cartoon slideshow (2MB version) only
   - Projects: Save locally as "Pending Sync"
   - Lesson plans: Use cached NCDC template
   - No Gemini API calls

B. MOBILE DATA MODE (Data Saver):
   - navigator.onLine === true && navigator.connection.type === 'cellular'
   - OR navigator.connection.effectiveType includes '2g'/'3g'
   - Show yellow badge: "Mobile data - Data saver mode"
   - Before big downloads: Show confirm dialog
   - Default: Only download slideshow versions (2MB)
   - Setting "Download HD videos only on WiFi" = ON by default

C. WIFI MODE (Full HD):
   - navigator.onLine === true && navigator.connection.type === 'wifi'
   - OR connection.effectiveType includes '4g'
   - Show green badge: "WiFi connected - Full HD mode"
   - Auto sync all pending items
   - Full Gemini API access

Fallback for browsers without navigator.connection:
   - Ask user on first launch: "What is your internet? [WiFi] [Mobile Data] [No internet]"
   - Save preference in IndexedDB

6. offline_settings
