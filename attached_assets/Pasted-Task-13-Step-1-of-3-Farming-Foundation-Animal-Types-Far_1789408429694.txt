PART H: ANIMAL MOVEMENT TRACKING
═══════════════════════════════════════════════════════════════

This is the CORE feature — detecting animals in/out.

When camera detects an animal crossing (gate camera):
1. Capture snapshot
2. Detect animal type (Cow/Goat/etc.)
3. Determine direction (IN/OUT)
4. Save to farm_animal_movements
5. Update today's running count

DETECTION APPROACH (lightweight, no paid APIs):

Since this must work without expensive AI:
1. Motion detection in camera frame
2. When motion > threshold → capture snapshot
3. Basic animal classification by size + shape (pre-trained 
   on-device model OR simple heuristics)
4. Direction detection: track movement across 2-3 frames
   - Object moving from left→right at gate = OUT
   - Object moving right→left = IN
5. Assign to animal type based on size:
   - Large (Cow/Donkey): > 50% frame height
   - Medium (Goat/Sheep/Pig): 20-50% frame height
   - Small (Chicken/Cock): < 20% frame height

FALLBACK:
If detection confidence < 60%:
- Save as "unclassified" movement
- Flag for manual review
- Farm Manager can reclassify

MOVEMENT LIST:

PART K: MISSING ANIMAL ALERTS
═══════════════════════════════════════════════════════════════

When an animal goes OUT but doesn't return by end of day:

1. System detects: OUT count > IN count for same animal type
2. Creates alert in farm_daily_summaries.alerts
3. Sends notification to:
   - Farm Admin (in-app + SMS)
   - Farm Manager (in-app)
   - Assigned Herder (in-app)
4. Alert message: 
   "⚠️ {N} {animal type} missing. Last seen at {time}."

Options:
- [Mark as Found] — updates count, removes alert
- [Report Lost] — logs lost animal in farm_lost_animals
- [Ignore] — dismisses alert (with reason)
